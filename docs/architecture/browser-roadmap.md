# Vezham Browser workflow and validation sequence

**Sequencing decision:** The product owner scheduled developer code signing/Apple notarization and macOS 26 runtime verification for the final release-validation stage. These are unverified release conditions, rather than blockers for current Phase 3 work.

| Stage                    | Work                                                                                                                         | Status                                                                                                                                                                                                                            |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Phase 1                  | Architecture and engine research                                                                                             | Documentation complete                                                                                                                                                                                                            |
| Phase 2                  | Internal distribution and security architecture                                                                              | Documentation complete; ADR 0002 Accepted                                                                                                                                                                                         |
| Phase 3                  | Native feasibility investigation                                                                                             | Bounded closure APPROVED; historical evidence and unresolved conditions retained in the [exit review](phase-3/phase-3-exit-review.md) and [owner decision](phase-3/owner-approval-decision.md)                                    |
| Phase 4                  | Engine decision and architecture baseline                                                                                    | Closure/baseline APPROVED; WKWebView CONDITIONAL ACCEPTANCE for MVP planning and implementation; reviewed ADR 0001 remains Proposed                                                                                               |
| Phase 5                  | Browser foundation                                                                                                           | M0 native-host foundation Passed within its bounded scope; [reports](phase-5/reports/README.md). M1-M8 remain Not Started. Swift/AppKit host, engine-independent core and future React/TypeScript/HeroUI v3 chrome stay separate. |
| Final release validation | Developer ID code signing, Apple notarization and distribution checks; macOS 26.0/latest supported 26.x runtime verification | Deferred to this final stage by user direction; required before internal release                                                                                                                                                  |

The current host remains macOS 27.2 and the build target/minimum remains macOS 26.0. Public-page-only testing remains in force. Native denial, 30 bounded content-process recoveries and an attributed ten-view aggregate-RSS observation now have evidence. Actual-window recovery passed 49 checks across A/B/Private and 48 existing regression checks passed on the same revision. Full permission lifecycle, durable recovery/in-flight crash cases, controlled performance and other product-feature gaps remain open. The separate conditional owner decision permits scoped implementation; it is not unconditional production-engine acceptance, does not pass unexecuted checks and does not waive security protections. ADR Stage A/B/C sequencing and [Phase 5 milestone dependencies](phase-5/phase-5-scope-and-milestones.md) apply.

Chromium/CEF remains evaluation-only. Aura and production Tamizhi/cloud dependencies remain excluded.
