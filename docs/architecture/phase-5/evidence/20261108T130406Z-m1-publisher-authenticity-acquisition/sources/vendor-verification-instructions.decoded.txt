      <h1>Verify SQLCipher</h1>

      <p>All SQLCipher binary packages prepared by Zetetic are provided with a digital signature in order to verify the authenticity of a downloaded package. Below are the steps to <a href="#prepare">setup</a> your environment, <a href="#acquire-key">obtain</a> the Zetetic Software public key and <a href="#signatures">verify</a> any packages you have acquired with their corresponding signatures.</p>

      <h2>Prepare Environment<a id="prepare" href="javascript:void();"></a></h2>

      <p>The steps below will describe the usage of <a href="https://www.gnupg.org/">GnuPG</a> (i.e. <code>gpg</code>), a free implementation of the OpenPGP standard. If you already have GnuPG installed on your host machine, please skip to the next <a href="#acquire-key">step</a>. Depending on your operating system there are a few options available for installing a GnuPG implementation. We recommend the following:</p>

      <ul>
        <li>OS X - <a href="https://gpgtools.org/">GPGTools</a></li>
        <li>Windows - <a href="https://www.gpg4win.org/">Gpg4win</a></li>
      </ul>

      <p>If you are running within a Linux environment, your distribution may already include a prebuilt version, if not, consult your package manager for specific installation instructions. To verify your installation on your machine, run the following command from your terminal &mdash; it should display the current version of the <code>gpg</code> tool:</p>
      
      <p class="command-line">gpg --version</p>

      <h2>Acquire Zetetic Software Key<a id="acquire-key" href="javascript:void();"></a></h2>

      <p>There are few ways to acquire the signing key, we will cover downloading and verifying the fingerprint of our key directly from S3 first.</p>

      <p>
        <a href="/security/support_zetetic_net_public_key.gpg" target="_blank" class="btn btn-primary btn-lg">Download Zetetic Signing Key</a>
      </p>

      <p>Before you import the key into your keyring, you should first verify the fingerprint of the key with the following command:</p>

      <pre><code>gpg --keyid-format 0xlong --with-fingerprint support_zetetic_net_public_key.gpg</code></pre>

      <p>This should print the following information, please verify the fingerprint matches:<a id="fingerprint" href="javascript:void();"></a></p>

      <pre>
pub   rsa4096/0xD1FA3A2A97ED25C2 2014-04-22 [C] [expires: 2027-08-02]
      Key fingerprint = D83F 5F9E B811 D6E6 B4A0  D9C5 D1FA 3A2A 97ED 25C2
uid                   [ unknown] Zetetic LLC &lt;support@zetetic.net&gt;
sub   rsa3072/0x0CB99EE267FD0322 2014-04-22 [S] [expires: 2027-08-02]
sub   rsa3072/0x3A7D809DD4DFEDA7 2014-04-22 [E] [expires: 2027-08-02]
sub   rsa3072/0x62AE2C1CB1C49DF6 2014-04-22 [A] [expires: 2027-08-02]
      </pre>
      <p>Now we can import the Zetetic key into the keyring. From a terminal prompt execute the following within the directory that contains the key:</p>

      <pre><code>cat support_zetetic_net_public_key.gpg | gpg --keyid-format long --import</code></pre>
      
      <p>Alternatively, you can request the key from a key server through the following command:</p>

      <pre><code>gpg --keyserver hkps://keys.openpgp.org --recv-keys D1FA3A2A97ED25C2</code></pre>

      <p>Again, we need to verify the fingerprint of the key matches <a href="#fingerprint">above</a>:</p>

      <pre><code>gpg --fingerprint D1FA3A2A97ED25C2</code></pre>

      <h2>Verify Signature<a id="signatures" href="javascript:void();"></a></h2>

      <p>With the Zetetic key properly installed in your keyring, you can now obtain the the corresponding signature(s) for the package(s) you have acquired.<p>

      <h3>Commercial and Enterprise Packages</h3>

      <p>Signatures for official SQLCipher packages are available directly from the <a href="https://license.zetetic.net/request-account/">Customer Download site</a>. Once you download a package and the appropriate signature, execute the corresponding command to verify the signature matches the package.</p>

      <pre><code>gpg --verify [file].sig [file]</code></pre> 

      <p>For example, the following command will verify the signature of a file called <code>sqlcipher-windows-4.20.0.zip</code> using the detached signature <code>sqlcipher-windows-4.20.0.zip.sig</code>:

      <pre><code>gpg --verify sqlcipher-windows-4.20.0.zip.sig sqlcipher-windows-4.20.0.zip</code></pre>
