## Cleanup and Source Ownership

- [Per-document cleanup manifest](../../evidence/20261107T151625Z-m0/documentation-cleanup-manifest.json) inventories every Browser/imported and pre-existing repository Markdown document, action, canonical location, reason and hash. Original import values are in [documentation-import.json](../../evidence/20261107T151625Z-m0/documentation-import.json). Source/evidence files are separately protected by preservation/source manifests.
- **Aligned in place:** platform, MVP acceptance, engine contract/comparison, distribution, roadmap; security architecture/threat model/criteria; ADR0002 context; Phase5 README/scope/plan. No mandatory requirement/checklist or ADR lifecycle changed. ADR0001 remains Proposed and unmodified.
- **Retained historical:** all Phase3 closeout/ledger/owner/baseline records, prototype reports, source/fixtures/evidence/manifests and architecture research. Statuses and distinct suites/revisions are not rewritten to reflect later authority or M0 results.
- **New navigation:** root README and Vx handbook index point to canonical Browser guidance; docs index, handbook summaries and Phase5 report/evidence indexes establish one entry per purpose.
- **New M0 records:** decisions, this mapping, exit report and unique run evidence contain actual M0 work only; no M1-M8 folders or empty subject placeholders.
- **Archives:** byte-identical snapshots were imported under Phase3 archives with provenance; originals remain in their earlier source locations. Archives are historical references, never current authority.
- **Superseded wording:** stale initial-engine-approval and all-final-gates-before-implementation statements in maintained documents were replaced by recorded conditional owner acceptance and StageA/B/C sequencing. No entire historical document was superseded/deleted. The per-file manifest identifies exact aligned sources; the original values remain in provenance hashes/source snapshot.
