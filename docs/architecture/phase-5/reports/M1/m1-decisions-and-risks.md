**Date:** 2026-11-07. **Status:** M1 design prepared for owner review; implementation Not Started.

Already approved: bounded Phase3 closure, architecture boundaries, internal macOS26.0+ deployment, Swift/AppKit host, future React/TypeScript/HeroUI v3 chrome, engine-independent core and conditional WKWebView planning/implementation direction. ## Deferred choices and access restrictions

Actual chrome origin/scheme/transport/CSP and binder tooling belong to M3; actual engine API/capability mapping to M2; permission-kind grant/revoke and transfer/temporary-resource semantics to M5; named critical workflows/accounts/media to M6; installer/updater/keys and OS/security response ownership to M7/M8. Public-pages-only restrictions continue. No production Tamizhi, identity/cloud feature, Aura, CEF implementation or public release is introduced. Local browsing remains independent of optional services.

No risk is marked mitigated by documentation alone. A cross-profile/private leak or unauthorized native action is a hard failure, not an acceptably documented implementation defect. macOS26.0/latest26.x runtime, DeveloperID/notarization, Gatekeeper/sandbox/Hardened Runtime/entitlements and internal updater/distribution gates remain mandatory and unpassed.
