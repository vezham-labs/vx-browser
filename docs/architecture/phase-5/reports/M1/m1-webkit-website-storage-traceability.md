## 4. SQLCipher applicability and unchanged gates

WebKit owns its website formats and storage I/O. Vezham owns catalog mappings, bookmarks/history/preferences/session projections, permission/download metadata and archive/deletion/recovery coordination. Persistent Vezham data retains the approved encryption/key/recovery requirements; private browser-owned state remains memory-only. WebKit classes remain their independent SPEC-08 protection domain.
