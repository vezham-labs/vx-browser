# Phase 5 Reports

Create a milestone folder only when actual work starts. Current records cover
[M0 foundation](M0/README.md), Passed within its scope, and
[M1 design](M1/README.md), prepared for owner review with implementation Not Started.
M2-M8 folders remain absent. A design completion assessment is distinct from a
milestone implementation pass.

A milestone report records date, scope, repository/branch/base SHA and dirty state,
source/configuration hashes, commands/outcomes, evidence links, limitations,
blockers and an explicit Passed/Partial/Blocked exit assessment. File creation
alone is not acceptance. Link run-specific raw artifacts from the
[evidence index](../evidence/README.md); do not merge them into Phase 3.

The [Phase 5 plan](../README.md) and [Browser handbook](../../../../vx/handbooks/browser/README.md)
provide navigation and continuing requirements. Report status is scoped to the
milestone and measured revision, not the whole product or release.
