## Design gaps surfaced by source review

- The catalog schema draft includes profile security and permission tables. Proposed per-profile grant storage and the unique profile-key boundary require explicit data placement, access authority and encryption ownership. No schema change is proposed in this report. [Catalog draft](../../../../../qualification/webkit-storage-f0/Sources/BrowserPersistence/ProtectedCatalog.swift), [encryption specification](../M1/m1-persistent-profile-encryption-specification.md)
- The model `PublicationPolicy` (29–55) requires catalog, profile and engine membership. The synthetic owned archive path is separate. A production owned-only archive needs an explicit manifest/resource contract and an exclusion for engine data. A placeholder “engine succeeded” receipt would misstate coverage. Preserve separate engine-inclusive qualification. [Model](../../../../../qualification/webkit-storage-f0/Sources/BrowserCore/Policies.swift), [archive](../../../../../apps/browser-macos/StorageRuntime/Sources/BrowserNativeStorage/EncryptedOwnedBackup.swift)
- A named-store lookup can create a store. Existence enumeration is a guard, with a race between enumeration and lookup. Absent/inconsistent mappings and ambiguous receipts must remain fenced. No race exploit or runtime failure is asserted from this code review. [Native adapter](../../../../../apps/browser-macos/StorageRuntime/Sources/BrowserNativeStorage/NativeWebKitStorage.swift)
- A scope and view-generation check around a native permission await needs an explicit same-document/origin binding and terminal outcome oracle. View retirement, denial policies and absent log markers do not establish native capability support or a complete denial path. [Mediator](../../../../../apps/browser-macos/StorageRuntime/Sources/BrowserNativeStorage/NativePermissionMediator.swift), [failure analysis](../WS-F2R-owner-handoff/native-failure-analysis.md)
- This review found no production protected database path in the inspected composition. Inventory of authorized actual formats and files would be a separate prerequisite for any migration. [Persistence plan](../M1/local-persistence-architecture.md), [handoff status](../WS-F2R-owner-handoff/implementation-status.md)
