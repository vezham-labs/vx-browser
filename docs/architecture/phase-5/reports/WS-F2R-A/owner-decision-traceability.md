## Related owner-decided policy and engineering trace

| Policy | Design consequence | Evidence route |
|---|---|---|
| OP-01 history | Store the approved credential-stripped URL representation, including query and fragment, behind profile protection. Default Forever and honor supported retention. These bytes and derived search keys are sensitive. | RECOVERY-004 covers the navigation/history boundary. Dedicated product retention, individual/range/all deletion and restore-reconciliation evidence is still required. Reconcile custom duration wording with OD-R12. |
| OP-02 downloads | Removing download history or deleting a profile cannot delete an external file. Deletion of an actual file requires a separate authorized operation. | RECOVERY-009 and authorized file transfer/deletion cases, including collision and moved files. |
| OP-03 snapshots | User-created snapshots remain separate from internal restart/crash descriptors and staging. | Supporting recovery charter, backup manifest and publication cases. |
| OP-04 session recovery | Normal quit/restart restoration according to owner policy; crash offers a prompt; recently closed is manual. Never restore private state, replay POST/forms or reopen locked/deleted scopes. Report unavailable pages as failures. | Recovery charter, safe-navigation and kill/relaunch cases; no engine-cookie backup inference. |
