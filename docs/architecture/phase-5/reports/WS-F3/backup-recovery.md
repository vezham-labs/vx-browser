# Backup and recovery

Existing native CryptoKit and owned-file synthetic archive coverage exercises bounded input and failure controls. It cannot establish a coherent production snapshot, portable key custody, protected import, interrupted restore or cross-Mac recovery. The WS-F3 provider probe does not perform product backup, restore, schema migration or recovery writes. Any fixture fingerprint occurs after key application under the read-only fence.

Production archives must be encrypted, authenticated, owned-only by default, and preserve original input and older backups through verification. Exclude private metadata and website storage. Use independent deletion records where available and explicit confirmation for unknown lineage. Exclude external downloads by default and require explicit selection and no-overwrite handling. These remain mandatory.
