# History, bookmarks and sessions

Production history, bookmarks, current and recently closed sessions and restart recovery remain unimplemented behind the protected adapter. No substitute writes to plain SQLite. Preserve the approved URL semantics including query and fragment with embedded credentials stripped, Forever default and selected retention/deletion. Keep history, bookmark records, approved restart descriptors and user snapshots distinct. Crash restore requires a prompt, recently closed restore is explicit, and safe navigation excludes forms, POST, private and locked/deleted scopes.
