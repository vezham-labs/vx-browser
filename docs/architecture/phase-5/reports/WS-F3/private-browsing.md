# Private browsing

The existing native adapter uses WKWebsiteDataStore.nonPersistent() for private sessions. Core's private scope does not persist product history, descriptors, permissions or backups. The previous private lifecycle and process-termination evidence is preserved. WS-F3 did not wire a new production private UI or implement protected private-to-normal interactions. The current scope of runtime re-execution is listed in the [qualification matrix](qualification-matrix.md). No claim is made about complete filesystem residue or forensic erasure.
