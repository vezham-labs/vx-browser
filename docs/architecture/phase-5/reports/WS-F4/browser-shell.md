# Browser shell

- **Start page** · Opens with no active profile. Starting private browsing is explicit. The new-tab page uses the same address and search validation and shows only manually added session bookmarks.
- **Tab strip** · Actual views, selection, creation, closing, duplication, scroll overflow, loading progress, text titles, move commands and drag reordering. The site icon is generic. Browser favicons and tab groups remain future work.
- **Navigation** · Back, forward, reload and stop, URL normalization, explicit submit to DuckDuckGo, local suggestions, address copy/paste and connection status derived from the actual WebKit view. Keyboard shortcuts include Cmd-L/T/W/R/K, Cmd-comma and Cmd-[ / Cmd-].
- **Sidebar** · Tabs, bookmarks, history, downloads, profiles and settings with adjustable width. Bookmarks support a session toolbar, folders, edit, search, move and remove.
- **Private session** · Multiple tabs share the one nonpersistent session store. Ending or closing the final tab closes its scope. Each subsequent session receives a fresh identity.
- **Settings** · Appearance uses the existing typed low-sensitivity setting. Privacy, permissions and protected profile sections explain actual availability. No site permission grant or locked/unlocked state is simulated.
