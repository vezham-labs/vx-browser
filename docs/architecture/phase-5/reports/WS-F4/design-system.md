# Design system

Vezham uses ink and mint in a compact navigation workspace, quieter neutral surfaces in content areas and a single accent for selection and the primary action. HeroUI v3 provides button and input interactions, Tailwind v4 provides the established CSS integration, and local tokens supply light, dark and system appearances. The start page uses a native system font, a small wordmark and a restrained geometric motif. No network fonts or images load in the chrome.

The AppKit title bar retains its macOS window controls. The toolbar groups navigation, address and command actions. Side rail icons have labels, icon-only controls have accessible names, and keyboard focus and reduced motion are explicit. The command palette supports focus entry, escape, arrow movement and focus return. Sidebar width is adjustable by pointer or keyboard. The workspace adapts to the minimum window width without moving website content over the chrome.

Studied product patterns include Safari's profile and toolbar context, Arc's sidebar and command entry, Vivaldi's panels and searchable commands, Chrome's combined address/search field, and Orion's visible profile identity. Vezham uses the same address field for explicit destinations and queries, with local suggestions and a separate private entry.
