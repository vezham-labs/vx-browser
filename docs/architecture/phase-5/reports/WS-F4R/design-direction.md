# Design direction

Arc is the primary interaction reference. Vertical tabs are the main navigation surface, Spaces organize session work, pinned tabs sit above named groups and ordinary tabs, and the command bar searches actions, tabs and Spaces. The compact toolbar focuses on the active page. The mini-browser is named Vezham Mini in the product.

Vezham retains its own geometric mark, mint accent, restrained neutral colors and native system typography. Light, dark and system appearances use the established setting. HeroUI v3 supplies accessible buttons and inputs. Tailwind v4 and local CSS reuse the existing build. The AppKit title bar and native split divider follow macOS behavior.

The reference study used Arc's published interaction descriptions. Spaces organize one private session. They do not establish profile encryption or a distinct website store.
