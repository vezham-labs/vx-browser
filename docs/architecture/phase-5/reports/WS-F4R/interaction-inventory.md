# Interaction inventory

| Interaction | Entry point and behavior |
|---|---|
| Tabs | Vertical list, New tab/command bar, keyboard selection, titles, favicon/loading/error state, close and duplicate |
| Reorder | Drag rows or Move up/down; stable view IDs |
| Pins | Context action moves a tab into pinned; unpin restores ordinary organization |
| Groups | Create, rename, reorder and ungroup; heading collapse; tab context action or drop assigns membership |
| Spaces | Create, rename and switch; move tabs by context action or drop; delete only an empty Space when another exists |
| Search | Filter tabs or search tabs/Spaces/actions in command bar; explicitly submit a destination |
| Split | Toolbar, command bar, tab context or sidebar drop target; heading/page focus, native divider, exit or close one pane |
| Mini | Tab context, command bar, target-blank page link and native URL entry; independent navigation, close and transfer |
| Sidebar | Toggle, pointer/keyboard resize, session preference |
| Appearance | Existing native system/light/dark setting |

Names are bounded to 40 characters and collection sizes are capped. A private session ends with its last tab or End session. [Tests](test-matrix.md)
