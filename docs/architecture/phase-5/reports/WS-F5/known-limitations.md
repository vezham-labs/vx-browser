# Known limitations

- Primary-button drag qualification is blocked by the host's existing input permissions. Group, Space, pinned, split, cancellation and invalid-drop gestures require a hands-on pass.
- VoiceOver speech and caption behavior remain inconclusive. Native keyboard and AX observations cover a bounded subset.
- The current candidate supports private sessions. Protected profiles, custody, authenticated unlock, persistent permissions and durable backup remain separate gates.
- Public HTTPS and loopback HTTP are admitted. Successful downloads and authenticated workflows are open. Public rendering checks cover six landing pages.
- Real content-process crash recovery, extended resource stress and a broader native accessibility walkthrough remain open.
- macOS 26.0 and latest supported 26.x runtime tests remain deferred. Final release still requires Developer ID signing, notarization, Gatekeeper, distribution, updater and the remaining release gates.
