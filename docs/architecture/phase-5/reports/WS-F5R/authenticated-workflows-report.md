# Authenticated workflows

The WS-F5 Basic challenge fixture returns 401 for every attempt. It cannot establish a session. A later increment may use an owned loopback fixture with synthetic test accounts, bounded session tokens and deterministic redirects. Record status and assertions while excluding credentials and token values from evidence.

AU-01 through AU-06 cover synthetic authentication, redirect, continuity, logout, Mini/main isolation and a fresh private session. AU-07 covers external accounts and remains BLOCKED pending separately approved environments. [Owner access decision](../../../phase-3/owner-approval-decision.md)
