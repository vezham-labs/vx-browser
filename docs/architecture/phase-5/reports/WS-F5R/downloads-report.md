# Downloads

The current private browser adapter allows displayable responses or cancels the navigation. It has no native download lifecycle. The application sandbox entitlements permit sandboxed execution and outbound network access. [Response policy](../../../../../apps/browser-macos/StorageRuntime/Sources/BrowserNativeStorage/NativeWebKitStorage.swift#L472) · [Entitlements](../../../../../apps/browser-macos/Config/VezhamBrowser.entitlements)

DL-01 through DL-08 begin with an investigation under the existing entitlements. Use owned deterministic attachments and disposable destinations. Any destination that needs additional authority stays blocked pending a separate decision. The [Phase 3 results](../../../prototype/wkwebview-test-results.md) are feasibility evidence from a different binary. Current-candidate download success remains BLOCKED.
