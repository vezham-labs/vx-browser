## Downstream gates

- **WS-F6 Workspace Foundation.** Layout model, version and failure contract, demand admission, Split Screen and Mini target behavior, synthetic and native-fixture qualification. Land in small reviewable changes. W1 is independently reversible. W2 changes lifecycle assumptions and needs review before W3 or W4. Changes to the current private recovery path are outside the fixture slices and need separate authorization and reruns.
- **WS-F7 Persistence and Security.** Approve real metadata retention, then implement and qualify the protected catalog write path, signed Keychain custody, profile/store binding, lock/clear/delete behavior, permission lifecycle and backup/recovery. No real-user persistence before G5 prerequisites on the production path. Use the existing Option D and exact D2A-01 authority.
- **WS-F8 Release Qualification.** Produce the approved Developer ID signed/notarized internal candidate, qualify Gatekeeper, clean install and upgrades/rollback, sandbox/entitlements and updater trust, and run actual macOS 26.0/latest supported 26.x, compatibility, accessibility and performance. Retain any WS-F5R unresolved case in its existing ledger and keep signed release acceptance separate from fixture results. Run the existing multiple-profile window and approved performance oracles, including their controlled machine, sampling and resource-accounting rules.
