# WS-F6 implementation qualification ledger

**Actual status, 10 November 2026.** This ledger records the outcome against the full scenarios in the [original planning matrix](qualification-matrix.md). A passed subcase cannot pass the entire scenario. NOT_EXECUTED retains the full-case status where a planned permutation is missing, even when narrower observations passed. BLOCKED identifies a required authority, oracle or persistence prerequisite.

The final native workspace run records 36 PASS_NATIVE and 7 PASS_CONTRACT observations. The injected recovery run records 34 PASS_NATIVE and 11 PASS_CONTRACT observations. These counts are assertions on one candidate, separate from the 40 scenario dispositions. Core/model, storage, navigation and stand-in evidence use their own layers.
