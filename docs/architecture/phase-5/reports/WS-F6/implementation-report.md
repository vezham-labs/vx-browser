## Decisions resolved during implementation

- **Normal retention and replay.** Layout encoding contains no destination, title, request or engine state. Synthetic model round trips preserve logical organization. The current product exposes private browsing only, so it writes no workspace snapshot and does not restore URLs on startup. A private workspace switch retires its old scope and retains the logical graph as blank slots. F7 must provide any normal protected persistence and reviewed retention policy.
- **Mini eligibility.** Accept only a successful, explicitly host-issued GET whose `WKNavigation` commits in the owned main frame at the same parsed destination. Reject query/fragment URLs, credentials, redirects and unknown provenance. Website navigation, Back/Forward and Reload clear that direct-load provenance. A fresh address load can establish it again. These conservative restrictions are visible through the disabled handoff action and form a documented limitation.
- **Logical private recovery.** Migrate the current private layout to logical IDs and remove every old binding on confirmed retirement. Recovery preserves organization and begins with zero website views or transferred URLs, cookies, auth, grants or page history.
- **Ownership and cleanup.** The existing MainActor host serializes UI commands, with value-based atomic model mutations. No extra coordinator runtime or dependency is introduced. Detached content relinquishes first responder before retirement. Native close observes this view/configuration pair weakly for up to 15 seconds; an unresolved reference still returns failure and leaves scope acquisition fenced.
- **Construction failures.** Core quarantines uncertain construction/activation failures at scope level. The implementation preserves that rule. A pane-local retry after such a failure requires a separately reviewed Core outcome that proves safe ownership. The model continues to preserve the layout.
- **Qualification exit.** The isolated F6 bundle awaits and records shutdown before its final termination request. Its exact Debug bundle/argument guard returns immediate termination after that shutdown. Normal product termination retains its asynchronous cleanup path. The suite therefore proves the recorded shutdown method, with final normal application quit qualification still in the release backlog.
