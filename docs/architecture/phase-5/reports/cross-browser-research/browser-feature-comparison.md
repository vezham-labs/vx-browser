# Browser feature comparison

**S** = observed in source or patch. **D** = documented by the project. **C** = project claim awaiting independent verification. **I** = inference. **U** = unverified in this review. A dash is used only where a feature is explicitly excluded. Competitor binaries were not run. The [source inventory](source-inventory.md) pins public repositories and identifies the evidence behind each row.

## Product workflows

| Browser | Workspace, tabs and hierarchy | Commands, keyboard and discovery | Split and temporary browsing | Restore and appearance |
|---|---|---|---|---|
| Vezham | **S** Vertical tabs, window-local Spaces, pins and flat groups | **S** Typed tab/Space/action bar, menu and shortcuts. Native VoiceOver walkthrough open | **S** Two WebKit panes; narrow fallback. Independent private Mini; explicit URL handoff | **S** Blank-layout recovery in memory; no restart restore. Light/dark/system setting persists |
| Arc | **D** Spaces, Today, pinned tabs, Favorites and nested folders; Profiles are separate from Space organization | **D** Command Bar, MRU Tab Switcher, menu and settings shortcuts; migration/export guides | **D** Split View, Peek and Little Arc are distinct workflows | **D** Sidebar state, archiving, themes, export and historical sync; exact lifecycle **U** |
| Little Arc | **D** Temporary window with workspace destination in main Arc; no separate Space model documented | **D** Quick entry and explicit Open In. Vendor recorded wrong-Space/Profile fixes | **D** Independent window UX, distinct from Peek overlay. Live handoff and storage mechanisms **U** | **D** Historical archive can include closed Little Arc links. Restart, privacy and visual settings follow Arc product context, internals **U** |
| Search | **S** Spaces, pins, groups and profile/Space configuration. **D** Horizontal or vertical tabs | **D** Combined address/search, tab switcher and shortcut menus. **S** Settings index | **S** Two resizable panes and persisted pairs. Window management exists. External-link triage equivalent to Little Arc **U** | **S** Saved rows and selected layout, lazy views, tab sleep. **D** Light/dark/system |
| SigmaOS | **D** Workspaces with lockable pages, hierarchical subpages, mark done and snooze | **D** Lazy Search, command palette, shortcut cheat sheet and insert mode for web apps | **D** Two-page Split Screen with Shift modifiers, Command-hover preview | **C** Autosync and idle page suspension. **D** Workspace customization; restart payload **U** |
| Zen | **S** Vertical sidebar, Workspaces and profile-level session records. **D** Optional Firefox container assignment and Essentials | **D** Firefox-style URL bar, workspace bindings, discoverability docs, configurable shortcuts | **S/D** Split View and Glance, with close, expand and split actions | **S** Session backup, workspace and split integration; Compact Mode, gradients and Mods |
| Cra | **S/D** Spaces, Today, favorites, pins and folders, native UI and Arc import | **S/D** Command bar and native controls, remappable shortcuts, skippable first-run steps | **S/D** Split View and Little Windows with destination workflows | **D** Relaunch history and archive; theme options. **S** Session/profile and browser creation paths; full restoration fidelity **U** |
| Stedding | **S/D** Chromium vertical tabs with Spaces, Essentials, nested folders, pins and Arc import | **S/D** Command bar, command list, shortcuts and first-run flow | **S/D** Split, Peek and Little Window; build-level parity untested | **D** Sidebar persistence, user-configured sync and Space export, themes and dark pages. **S** Space sleep work |
| Flecha | **S/D** Spaces, favorites, pins, folders and Today/archive | **S** Developer aliases, regular command bar, local/staging/prod shortcuts and onboarding source | **S/D** Patched split, Peek and Flechinha handoff | **S/D** Shell state, window placement, archiving and theme. Native tab restore behavior by build **U** |
| Refrax | **S/D** Vertical or horizontal organization, Spaces/groups, per-tab engine choice and profile modes | **D** Command Lens, keyboard operation and CLI. Guided onboarding **U** | **D** Pinned-tab preview; user-facing two-pane and Mini equivalents **U** | **S** Browser-owned tab persistence and deferred page creation during window initialization. **D** Native Liquid Glass appearance |
| Vela | **S/D** Spaces, vertical sidebar, profiles, pins and nested folders with Arc migration | **D** Command palette, shortcut reference and first-run importer | **S/D** Split, Peek and Little windows, with separate view placement | **S** Workspace state and lazy view creation/sleep. **D** Themes and per-site Boosts |

## Architecture, privacy and developer experience

| Browser | Engine, host and view lifecycle | Storage, permissions and downloads | Extensions and control | Performance evidence |
|---|---|---|---|---|
| Vezham | **S** AppKit host with bundled web chrome and system WebKit. Eager tab creation, private scope fence and explicit replacement | **S** One private store per workspace/Mini session; protected catalog closed. Permission gate; no successful download flow | **S** Debug fixture runners and typed chrome bridge. Public extension/automation surface absent in composition | Historical native/contract/stand-in evidence. Current comparative baseline **U** |
| Arc | **D** Chromium. Local Vezham repo records historical ArcCore and helper inspection, without public app source | **D** Profiles/incognito, downloads and Chromium extension UX. Exact key custody, isolation mechanics and backup boundary **U** | **D** DevTools and Chrome extensions. External command/control scope **U** | **C** Vendor optimization notes. **D** Third-party-to-Arc Vela project benchmark for a historical build |
| Little Arc | **D** Arc UI surface. Dedicated process, live-view transfer and lazy scheduling **U** | **D** Profile destination cues and historical archive. Store mapping, permission/download attribution and private retention **U** | Separate automation and extension behavior **U** | **C** Arc notes on sidebar stalls. No standalone benchmark located |
| Search | **S** SwiftUI/AppKit, WKWebView, lazy realization, sleep, crash fallback and separate window paths | **S** Nonpersistent private tab configuration, persistent stores by Space/profile rules, JSON session metadata, Keychain vault, rule lists and WKDownload delegate | **S** WKWebExtension and extensive shims; AppleScript read surface and opt-in bench/isolated MCP harness | **C** Vendor launch and footprint claims; source supports mechanisms |
| SigmaOS | **C/D** SwiftUI/WebKit and idle unload; private app internals **U** | **D** Separate-cookie Workspaces and private shortcut. **C** Keychain and ITP. Store lifecycle, backup, download/permission behavior **U** | **D** Selected extension install workflow; compatibility breadth, automation and security model **U** | **C** RAM and battery positioning |
| Zen | **S** Firefox build/patches and Gecko browser integration; uses upstream multiprocess/session machinery | **S/D** Workspaces can map to Firefox containers; storage/history and extensions have separate policies. Session backups and download UI. Exact recovery/custody untested | **S/D** Firefox WebExtensions integration, DevTools and Zen Mods. Product MCP/CLI **U** | No comparable independent measurement located |
| Cra | **S** Swift AppKit/SwiftUI and CEF, narrow WKWebView path for selected protected media; renderer termination callback | **S** CEF contexts for profiles/incognito and Keychain Safe Storage; native download/permission surfaces. Exact runtime security guarantees **U** | **D/S** Chromium extensions, DevTools, cra:// commands. WebKit media path has reduced features | Project performance tooling. Current equivalent cohort **U** |
| Stedding | **S** Chromium patches over an upstream pin with Space sleep/placement | **S/D** Cookie partition per Space, shared profile history/passwords/extensions, Chromium downloads and settings; optional blocking. Vendor discloses Safe Browsing gap | **D/S** Chrome extensions and DevTools. Broad CLI/MCP control **U** | Project historical same-pin comparison, no current measurement according to project |
| Flecha | **S** Chromium fork with MV3 component shell and Node native messaging host. Historical Electron implementation is superseded | **S** Separate-cookie patch, incognito shell and Chromium storage, blocking rules, host importer. **D** Download destination settings gap | **S** Chromium DevTools and Chrome extensions, loopback MCP with bearer auth and page action tools | No comparable independent measurement located |
| Refrax | **S** App plus built-in WebKit and separately installed Chromium bridge/helpers. Engine and page crash handling contracts | **S/D** Shared/isolated/ephemeral stores, Space lock, Keychain and per-engine policy/downloads. Cross-engine website data equivalence **U** | **S** Local CLI with peer identity policy; WebKit extension integration/shims. Full parity **U** | No comparable independent measurement located |
| Vela | **S** Electron/Chromium main process with shell and sandboxed WebContentsViews; view destruction and renderer-gone handling | **S** Profile partitions, permission prompts, downloader and secret import paths. Private view/session semantics across all paths **U** | **S/D** Electron extension subset, DevTools and Boosts. Product MCP/CLI **U** | Project-published Arc comparison with raw data; different builds/engines and no Vezham run |

Product labels and appearance are transferable at the interaction level. Store mapping, renderer scheduling, live-view movement, backup, extension privilege and background behaviors require separate evidence.
