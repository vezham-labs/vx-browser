# Current Vezham architecture

Source baseline `f55619dfef819365dc0073166f430b22e70d8a02` on `timeline`. Source observations describe that revision. Historical counts below describe the named qualification candidate.

## Ownership and module boundaries

| Layer | Implementation and boundary |
|---|---|
| App and windows | `ApplicationDelegate` owns startup, menu, main-window reopen, a bounded external route queue and awaited termination. `MainWindowController` owns AppKit window/layout, session composition, tab/Space state and Mini controllers. The product has a workspace window and bounded Minis. General multi-workspace window restoration is absent. |
| Browser chrome | A separate nonpersistent `WKWebView` loads the bundled React/TypeScript and HeroUI UI. Native checks the originating view, current and message-frame URL, main frame, payload size and typed v1 command. Website views are separately configured. AppKit owns the content surfaces and split layout. |
| Domain and ports | Swift 6 `BrowserDomain` owns identities, storage descriptors and security models. `BrowserPorts` defines adapter contracts. `BrowserCore` coordinates admission, lifecycle, publication, permission and profile state. The app consumes these local targets from `qualification/webkit-storage-f0` via `BrowserStorageRuntime`. |
| Native storage | `NativeStorageSession` composes the run and authority, Core and WebKit/Security adapters. `NativeWebKitStorage` assigns and validates stores before construction, checks generation and operation on publication, and fences, quiesces, clears and retires resources. |
| Persistence | `BrowserPersistence` holds in-memory adapters, protected catalog gates and owned-backup policy. Native SQLite is allowlisted for global appearance only. Protected profile metadata, Keychain, unlock, persistent permissions and backup have adapters/contracts or fixture slices. Product admission remains unavailable. |

| Command bar and routing | Tab/Space/action search, address or search navigation, local shortcuts and native typed commands. LaunchServices HTTP/HTTPS events route through the workspace path. | Split Screen | An `NSSplitView` attaches two distinct tab surfaces in the same Space and session. The focused pane supplies commands. No product password vault, content blocker, extension host or external automation interface was located in the inspected product composition. |

## Recovery and qualification

At HEAD, an owned website termination callback poisons its private scope, invalidates pending navigation and permission state, and signals the host. The host detaches surfaces and waits for Core retirement, zero pending work/views, empty adapter inventory and revoked authority. Close takes precedence over starting a second retirement. On explicit user action the host builds a fresh session, stages fresh views, and remaps in-memory layout, pins, groups, selection and split intent. All recovered tabs start blank. The current recovery eagerly creates a view for every recovered tab slot. It carries no title, URL, cookie, auth, permission, request body or history across the reset. The originating Mini stays independent. Ambiguous retirement or failed staging leaves the workspace unavailable. ## ADRs and persistence reconciliation

ADR 0001 is Proposed with conditional WKWebView acceptance for MVP. ADR 0002 is Accepted and sets macOS 26+ and Developer ID/notarized internal direct distribution. ADRs 0003–0005 remain Proposed and document Swift module boundaries, protected browser-owned state and capability/lifecycle design. Native admission and historical source evidence should retain their individual dispositions.
