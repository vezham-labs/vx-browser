# Workspace and tab UX

## Workspace and tab hierarchy

Arc separates temporary Today tabs from pins and Favorites. Stedding, Cra and Vela preserve those concepts in migration because tab tier, order and hierarchy carry meaning. Vezham already has vertical tabs, Spaces, pins and flat groups. Preserve and explain those semantics first. Make moving to a Space, grouping, pinning, and closing deterministic from both the command bar and context menu. Test discovery with a fresh workspace and VoiceOver, and with a populated multi-Space workspace. Defer nested folders, automated archival and a separate Favorites tier until observation shows a problem that flat groups and pins cannot solve. [Arc documentation](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions) · [Cra help](https://crabrowser.app/help) · [Stedding](https://stedding.dev/)

SigmaOS treats pages like tasks with Done, Snooze and subpages. Its command help and insert mode demonstrate discoverability and the need to preserve website input. For Vezham, rank exact matches in the active Space, label results from other Spaces and distinguish opening, switching and executing. Display shortcuts for supported actions and provide a keyboard equivalent for moving/reordering where physical drag is inconvenient. Keep plain typing in pages and fields under page control. Treat task semantics as a separate, later study. [SigmaOS shortcut guide](https://docs.sigmaos.com/cheat-sheet) · [Lazy Search](https://docs.sigmaos.com/tutorial/pages)

Zen can pair a workspace with a Firefox container, but its documentation distinguishes cookie separation from browsing history and extension state. Use distinct indicators for Space, profile and private session. The Space selector should communicate organization. Any future switch to another data authority should be explicit. Zen's Compact Mode motivates a constrained look at keyboard reveal and focus continuity, with persistent access to destination and privacy cues. [Zen Workspaces](https://docs.zen-browser.app/user-manual/workspaces) · [Compact Mode](https://docs.zen-browser.app/user-manual/compact-mode)

## Temporary browsing and handoff

Little Arc is a temporary **window** and Arc Peek is an **overlay**. Zen Glance similarly offers a preview that can close, expand or join a split. Mini is closer to Little Arc. Its independent private store is a defining interaction boundary. Clarify which main window or Space will receive the link, how reauthentication may differ, and when handoff failed. Treat transfer as an authorized URL open in the target and make the lifetime of the source window predictable. Avoid silent fallback to another Space. Validate on cold/warm routing, destination changes while the Mini is open, denied/busy destinations, two Minis, focus return, bad redirects and authentication markers. [Arc release notes](https://resources.arc.net/hc/en-us/articles/20498293324823-Arc-for-macOS-2024-2026-Release-Notes) · [Zen Glance](https://docs.zen-browser.app/user-manual/glance) · [Vezham Mini implementation](../../../../../apps/browser-macos/Sources/Host/MainWindowController.swift#L665)

## Split and onboarding

Search persists pairs with widths. SigmaOS mirrors core actions onto the side pane using Shift. Keep Vezham's two-pane model and teach a short set of actions that make the target visible, such as Open in Split and Focus Other Pane. Save divider preference and focused member within a workspace only after validating both IDs against its current scope. Make the compact fallback legible and recover both panes when width permits. Validate keyboard, pointer and VoiceOver transitions independently. [Search](https://github.com/driceroland/Search/blob/e198e77b6e57519d6ceb0d13a816757dffa586ad/Sources/Search/SplitView.swift) · [SigmaOS Split Screen](https://docs.sigmaos.com/tutorial/split-screen)

Cra's skippable setup and Stedding/Vela import descriptions suggest that migration is easier when users can inspect what will arrive. Vezham can introduce command shortcuts and explain temporary vs. durable state in context. Investigate a later preview of URLs and folder structure from an explicit file. Show counts, conflicts and destination before a reversible import. Export from Arc is documented as a link list, so preserving every nested field is format-dependent.
