## Build defect corrected

A clean build under Nx produced a blank shell and `(0 , q.jsxDEV) is not a function`. The Vite 8.1.6 transform inherited development JSX while `define` selected production React. The existing Vite configuration now explicitly uses `oxc.jsx.development = false`, matching its production-only bundled React runtime. The first UI attempt failed 16/16 and is preserved. After the configuration fix and rebuild, all 16 tests passed. This repairs the retained shell; it does not migrate it.

Generated `apps/browser-macos/build/**` bundles were also being linted, yielding 9,626 errors in source plus generated libraries. The root ESLint ignore now excludes that generated directory. The remaining 30 source diagnostics were already present at the initial revision; no source lint failure is relabeled as a pass.
